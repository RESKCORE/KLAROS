3 Complete Mathematical AHP Walkthrough with Indian Rupee (₹) Example

To demonstrate the exact formulas, let us trace a real execution with a sample 3-product supermarket batch.

3.1 The Sample Supermarket Dataset

SKU Product Name Unit Price (P) Unit Cost (C) Daily Units Sold (Q) Current Stock (S) Reorder Point (R) Operational Status
SKU-01 Fresh Milk 1L ₹60 ₹50 100 units 20 units 80 units Critical Stockout (S < R)
SKU-02 Gourmet Cookies ₹200 ₹80 10 units 500 units 50 units Severe Overstock (10x R)

3.2 Deterministic Financial KPI Computation (TypeScript Web Worker)

1. Total Revenue = Σ (Unit Price × Quantity)
Revenue = (₹60 × 100) + (₹200 × 10) + (₹500 × 20) = ₹6,000 + ₹2,000 + ₹10,000 = ₹18,000

2. Total Cost = Σ (Unit Cost × Quantity)
Cost = (₹50 × 100) + (₹80 × 10) + (₹400 × 20) = ₹5,000 + ₹800 + ₹8,000 = ₹13,800

3. Net Profit & Gross Profit Margin %
Profit = ₹18,000 - ₹13,800 = ₹4,200
Margin % = (₹4,200 / ₹18,000) × 100 = 23.33%

4. Product Margins & Stockout Ratios (Stock / Reorder)
• Fresh Milk: Margin = (60 - 50)/60 = 16.67% | Stock Ratio = 20 / 80 = 0.25 (Critical Alert)
• Gourmet Cookies: Margin = (200 - 80)/200 = 60.00% | Stock Ratio = 500 / 50 = 10.0 (Overstocked)
• Organic Rice: Margin = (500 - 400)/500 = 20.00% | Stock Ratio = 40 / 40 = 1.00 (Balanced)

3.3 What the LLM Generates (Qualitative Strategy & Pairwise Comparisons)

The LLM receives the structured KPI summary and returns 3 Strategic Options, 3 Evaluation Criteria, and Saaty 1–9 Comparison Triples:

3 Strategic Alternatives (O):
  • O1: Emergency Milk Restock & Supplier Reorder
  • O2: Discount Promotion on Gourmet Cookies (Clear Stock)
  • O3: Maintain Status Quo & Monitor Weekly Velocity
3 Evaluation Criteria (C):
  • C1: Stockout & Revenue Risk Mitigation
  • C2: Immediate Profit Margin Preservation
  • C3: Working Capital & Holding Cost Liquidation

Criteria Comparison Triple: [C1 vs C2 = 3, C1 vs C3 = 2, C2 vs C3 = 1] (on Saaty's 1–9 Scale).

3.4 Building the Positive Reciprocal Criteria Matrix (M_C)

Given the comparison triple [a01 = 3, a02 = 2, a12 = 1], buildPairwiseMatrix() builds the 3×3 reciprocal matrix:

Matrix M_C = [ [1, c01, c02], [1/c01, 1, c12], [1/c02, 1/c12, 1] ]
[ 1.000, 3.000, 2.000 ]
[ 0.333, 1.000, 1.000 ]
[ 0.500, 1.000, 1.000 ]

3.5 Deriving Criteria Weights via Geometric Mean Method

In calculatePriorityVector(matrix):

Step 1: Compute Row Geometric Means: GM_i = (a_i1 × a_i2 × a_i3)^(1/3)
• Row 1 (C1: Stockout Risk): GM_1 = (1.0 × 3.0 × 2.0)^(1/3) = (6.0)^(1/3) = 1.8171
• Row 2 (C2: Margin Preservation): GM_2 = (0.3333 × 1.0 × 1.0)^(1/3) = (0.3333)^(1/3) = 0.6934
• Row 3 (C3: Capital Liquidation): GM_3 = (0.5000 × 1.0 × 1.0)^(1/3) = (0.5000)^(1/3) = 0.7937

Step 2: Sum Geometric Means & Normalize: w_i = GM_i / Σ GM_k
Sum Σ GM = 1.8171 + 0.6934 + 0.7937 = 3.3042

• Weight w_1 (C1): 1.8171 / 3.3042 = 0.5499 (55.0%)
• Weight w_2 (C2): 0.6934 / 3.3042 = 0.2098 (21.0%)
• Weight w_3 (C3): 0.7937 / 3.3042 = 0.2402 (24.0%)
Σ w_i = 0.5499 + 0.2098 + 0.2402 = 1.0000 (Exact 100%)

3.6 Principal Eigenvalue (λ_max) & Consistency Index (CI)

Step 1: Compute Matrix-Vector Product: y = M_C · w
• y_1 = (1.0 × 0.5499) + (3.0 × 0.2098) + (2.0 × 0.2402) = 0.5499 + 0.6294 + 0.4804 = 1.6597
• y_2 = (0.3333 × 0.5499) + (1.0 × 0.2098) + (1.0 × 0.2402) = 0.1833 + 0.2098 + 0.2402 = 0.6333
• y_3 = (0.5000 × 0.5499) + (1.0 × 0.2098) + (1.0 × 0.2402) = 0.2750 + 0.2098 + 0.2402 = 0.7250

Step 2: Compute λ_i = y_i / w_i and Average λ_max
• λ_1 = 1.6597 / 0.5499 = 3.0182 | λ_2 = 0.6333 / 0.2098 = 3.0186 | λ_3 = 0.7250 / 0.2402 = 3.0183
λ_max = (3.0182 + 3.0186 + 3.0183) / 3 = 3.0184

Step 3: Compute Consistency Index: CI = (λ_max - n) / (n - 1)
CI = (3.0184 - 3) / (3 - 1) = 0.0184 / 2 = 0.0092

3.7 Consistency Ratio (CR) Validation

✓ Consistency Ratio Verification (CR < 0.10)
Using Saaty's empirical Random Index for n = 3 (RI_3 = 0.58):
CR = CI / RI_3 = 0.0092 / 0.58 = 0.0159 (1.59%)
Since CR = 0.0159 < 0.10, the qualitative comparisons are mathematically consistent, transitive, and verified!

const SaatyValueSchema = z
  .number()
  .min(1 / 9, 'Saaty value must be >= 1/9')
  .max(9, 'Saaty value must be <= 9')

export const ComparisonTripleSchema = z.tuple([

7 Zero-Trust Security & Database RLS Architecture

Serverless RS256 Web Crypto Auth

The /api/llm proxy function uses Node 20's native crypto.subtle to verify the Clerk-issued RS256 JWT signature using Clerk's public PEM key before making any external AI API call.

  • Zero dependency bundle overhead (no jsonwebtoken package).
  • Eliminates cold-start latency on Vercel Edge.
  • Secret API keys stay strictly in encrypted Vercel environment variables.

PostgreSQL Row-Level Security (RLS)

Supabase enforces strict isolation matching the authenticated Clerk token claim against the table's user_id column:

CREATE POLICY "Users manage own decisions"
ON decisions FOR ALL
USING (auth.jwt() ->> 'sub' = user_id)
WITH CHECK (auth.jwt() ->> 'sub' = user_id);

8 Viva Presentation Q&A Cheat Sheet

Q1: Why did you choose AHP instead of Simple Additive Weighting (SAW)?
"SAW requires arbitrary percentage assignments which are cognitively biased. AHP decomposes evaluations into 1-to-1 pairwise comparisons, computes mathematically exact weights via the Geometric Mean method, and programmatically validates judgment consistency using the Consistency Ratio (CR < 0.10)."
Q2: How do you prevent division by zero or NaN errors in AHP?
"Our `clampSaaty()` utility clamps all comparison values to [1/9, 9] and maps non-finite values to 1.0 (equal importance). In `calculatePriorityVector()`, if the geometric mean sum is zero, it safely falls back to a uniform distribution [1/n, ..., 1/n]."
Q3: How do you ensure high performance during 50MB CSV uploads?
"All dataset metric calculations run off-thread in a dedicated Web Worker (`market-metrics.worker.ts`). Sorting uses Schwartzian transforms to avoid O(n log n) Date object allocations, ensuring the React UI remains at 60 FPS."
Q4: Is the revenue forecast generated by an ML model or LLM?
"It is generated via structured in-context LLM time-series extrapolation using the last 30 daily data points. It is not an ARIMA or Prophet statistical model, which we have transparently documented in our limitations."
